# StellerSL Frontend

Frontend application for StellerSL, built with Vue 3, TypeScript, and Vite.

## Prerequisites

- Node.js (v20.x recommended)
- pnpm (v10.x recommended)

## Installation

1. Install dependencies:
   ```bash
   pnpm install
   ```

## Development

Run the development server:

```bash
pnpm dev
```

The application will be available at `http://localhost:5173`.

## Build

Build the application for production:

```bash
pnpm build
```

The build output will be placed in the `dist/` directory.

## Run with Docker

See [docker-compose.yml](docker-compose.yml) for instructions on running the application with Docker.
